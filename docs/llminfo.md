# LLM Info – SimCardAPNProvisioning

## Purpose
Provide machine-readable documentation for APN provisioning APIs to assist LLMs in answering developer queries.

## Key Features
- Automated APN provisioning
- Multi-profile support (`default`, `supl`, `mms`, `dun`)
- Authentication options (`None`, `PAP`, `CHAP`)
- Error handling with standard codes

## Integration Notes
- SIM must be active before provisioning
- Log `provisioningId` for audit
- Supports IoT/weather intelligence deployments
